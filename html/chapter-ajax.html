How AJAX Works in Laravel

Instead of loading a whole new page, your JavaScript sends a silent HTTP request to a Laravel route. The controller queries the database and returns JSON. JavaScript receives the JSON and updates just the part of the page that changed.

🔄 Traditional (Full Reload)
  • User submits form or clicks link
  • Browser loads a completely new page
  • All CSS, JS, images reload
  • User sees page flash/blank
  • Slow — especially on mobile
⚡ AJAX (No Reload)
  • JS sends silent background request
  • Only the data changes, page stays
  • No CSS/JS/image reload
  • Instant, smooth user experience
  • Works for search, filters, cart, more

Create a JSON Route & Controller

Any route can return JSON instead of a view. Just swap view() for response()->json(). The browser's Fetch API will receive it as a JavaScript object.

routes/web.php — add JSON routes 
// ── AJAX / JSON routes ──────────────────────────────
// These return JSON, not a view

// Search products
Route::get('/ajax/products', [ProductController::class, 'ajaxIndex']);

// Get single product detail
Route::get('/ajax/products/{product}', [ProductController::class, 'ajaxShow']);

// Get products by category
Route::get('/ajax/categories/{category}/products',
    [CategoryController::class, 'products']);

// Get cart count (auth users only)
Route::get('/ajax/cart/count', [CartController::class, 'count'])
    ->middleware('auth');
app/Http/Controllers/ProductController.php — ajaxIndex() 
public function ajaxIndex(Request $request)
{
    $query = Product::with('category')->where('stock', '>', 0);

    // Search filter
    if ($request->filled('search')) {
        $query->where('name', 'like', '%' . $request->search . '%');
    }

    // Category filter
    if ($request->filled('category_id')) {
        $query->where('category_id', $request->category_id);
    }

    // Sort
    $sort = $request->input('sort', 'latest');
    match($sort) {
        'price_asc'  => $query->orderBy('price', 'asc'),
        'price_desc' => $query->orderBy('price', 'desc'),
        'name'       => $query->orderBy('name'),
        default      => $query->latest(),
    };

    $products = $query->paginate(12);

    // Return JSON — JS will receive this as a plain object
    return response()->json([
        'data'         => $products->items(),       // array of products
        'current_page' => $products->currentPage(),
        'last_page'    => $products->lastPage(),
        'total'        => $products->total(),
    ]);
}
💡
Tip: Keep your AJAX routes alongside your normal routes in routes/web.php — not in routes/api.php. This way they share the same session, auth guard, and CSRF protection as your regular pages.

Fetch API Basics

The browser's built-in fetch() function sends HTTP requests and returns Promises. No jQuery or extra libraries needed.

resources/js/ajax.js — fetch() fundamentals 
// ── Basic GET request ────────────────────────────────
fetch('/ajax/products')
    .then(response => response.json())   // parse JSON string → JS object
    .then(data => {
        console.log(data);               // { data: [...], total: 50, ... }
    });

// ── async/await version (cleaner) ────────────────────
async function loadProducts() {
    const response = await fetch('/ajax/products');
    const data     = await response.json();

    console.log(data.data);        // array of products
    console.log(data.total);       // e.g. 50
    console.log(data.current_page); // e.g. 1
}

// ── GET with query parameters ─────────────────────────
const params = new URLSearchParams({
    search:      'laptop',
    category_id: 2,
    sort:        'price_asc',
    page:        1,
});

const response = await fetch(`/ajax/products?${params}`);
// Calls: /ajax/products?search=laptop&category_id=2&sort=price_asc&page=1

resources/js/search.js — live search with debounce 
const searchInput  = document.getElementById('searchInput');
const resultsDiv   = document.getElementById('productResults');
const spinner      = document.getElementById('spinner');
let   debounceTimer;

searchInput.addEventListener('input', () => {
    clearTimeout(debounceTimer);

    // Wait 350ms after user stops typing before fetching
    debounceTimer = setTimeout(async () => {
        const query = searchInput.value.trim();

        // Show spinner
        spinner.style.display = 'block';

        try {
            const params = new URLSearchParams({ search: query });
            const res    = await fetch(`/ajax/products?${params}`);
            const data   = await res.json();

            // Render results into the DOM
            renderProducts(data.data, resultsDiv);

        } catch (err) {
            resultsDiv.innerHTML = `<p class="error">Error: ${err.message}</p>`;
        } finally {
            spinner.style.display = 'none';
        }
    }, 350);
});

// Build HTML string from product data and inject it
function renderProducts(products, container) {
    if (products.length === 0) {
        container.innerHTML = '<p>No products found.</p>';
        return;
    }

    container.innerHTML = products.map(p => `
        <div class="product-card">
            <img src="/storage/${p.image}" alt="${p.name}">
            <h3>${p.name}</h3>
            <p class="price">₱ ${Number(p.price).toLocaleString()}</p>
            <p class="category">${p.category?.name ?? ''}</p>
            <button class="btn-add-cart" data-id="${p.id}">Add to Cart</button>
        </div>
    `).join('');

    // Re-attach cart button event listeners
    attachCartListeners();
}

resources/js/filter.js — category filter 
let activeCategory = null;

document.querySelectorAll('.category-btn')
    .forEach(btn => {
        btn.addEventListener('click', () => {
            // Update active state on buttons
            document.querySelectorAll('.category-btn')
                .forEach(b => b.classList.remove('active'));
            btn.classList.add('active');

            activeCategory = btn.dataset.id || null;

            // Update the URL without reloading the page
            const url = activeCategory
                ? `/products?category_id=${activeCategory}`
                : '/products';
            history.pushState({}, '', url);

            // Fetch filtered products
            fetchProducts({ category_id: activeCategory });
        });
    });

async function fetchProducts(filters = {}) {
    const grid = document.getElementById('productGrid');
    grid.style.opacity = '0.4'; // dim while loading

    const params = new URLSearchParams(
        Object.fromEntries(
            Object.entries(filters).filter(([k, v]) => v != null)
        )
    );

    const res  = await fetch(`/ajax/products?${params}`);
    const data = await res.json();

    renderProducts(data.data, grid);
    grid.style.opacity = '1';
}

Injecting Data into Blade Templates

You have two strategies: build HTML in JavaScript, or ask Laravel to return a pre-rendered Blade partial. The second approach is cleaner and keeps your HTML in one place.

📌
Strategy A — Build HTML in JS — fast, simple, all logic in one JS file. Good for small items like cards or list rows.

Strategy B — Return rendered Blade HTML — controller renders a partial view and returns the HTML string. JavaScript just drops it into the page. Best for complex components.
Strategy A — Build HTML directly in JavaScript 
// Controller returns JSON array of products
return response()->json(['data' => $products]);

// JavaScript builds and injects the HTML
function renderProducts(products, container) {
    container.innerHTML = products.map(p => `
        <div class="product-card" data-id="${p.id}">
            <img src="/storage/${p.image}" alt="${p.name}"
                 onerror="this.src='/images/placeholder.jpg'">
            <div class="product-card__body">
                <span class="badge">${p.category.name}</span>
                <h3>${p.name}</h3>
                <p class="price">₱ ${Number(p.price).toLocaleString('en-PH')}</p>
                <p class="stock ${p.stock === 0 ? 'out' : ''}">
                    ${p.stock > 0 ? p.stock + ' in stock' : 'Out of stock'}
                </p>
            </div>
            <button class="btn-add-cart" data-id="${p.id}"
                ${p.stock === 0 ? 'disabled' : ''}>
                ${p.stock > 0 ? 'Add to Cart' : 'Sold Out'}
            </button>
        </div>
    `).join('');
}
Strategy B — Controller returns rendered Blade partial 
// Controller renders the Blade partial and returns HTML string
public function ajaxIndex(Request $request)
{
    $products = Product::with('category')->paginate(12);

    // If AJAX request, return rendered HTML partial
    if ($request->ajax() || $request->wantsJson()) {
        return response()->json([
            'html'      => view('partials.product-grid',
                              compact('products'))->render(),
            'total'     => $products->total(),
            'last_page' => $products->lastPage(),
        ]);
    }

    // Normal browser request — return full page view
    return view('products.index', compact('products'));
}

// resources/views/partials/product-grid.blade.php
// Just the grid HTML, no layout wrapper
JavaScript — drop rendered HTML into the page 
const res  = await fetch('/ajax/products', {
    headers: { 'X-Requested-With': 'XMLHttpRequest' }
    // This header makes $request->ajax() return true
});
const data = await res.json();

// Drop pre-rendered Blade HTML straight into the DOM
document.getElementById('productGrid').innerHTML = data.html;

// Re-attach any event listeners after DOM update
attachCartListeners();

resources/js/pagination.js — AJAX pagination 
let currentPage     = 1;
let currentFilters  = {};

// Intercept pagination link clicks
document.addEventListener('click', async e => {
    const pageBtn = e.target.closest('[data-page]');
    if (!pageBtn) return;

    e.preventDefault();
    const page = parseInt(pageBtn.dataset.page);
    if (page === currentPage) return;

    currentPage = page;
    await fetchPage(page);
});

async function fetchPage(page) {
    const grid = document.getElementById('productGrid');

    // Fade the grid while loading
    grid.style.opacity = '0.3';
    grid.style.pointerEvents = 'none';

    const params = new URLSearchParams({
        ...currentFilters,
        page,
    });

    const res  = await fetch(`/ajax/products?${params}`);
    const data = await res.json();

    // Render products
    renderProducts(data.data, grid);

    // Rebuild pagination controls
    renderPagination(data.current_page, data.last_page);

    // Restore grid
    grid.style.opacity = '1';
    grid.style.pointerEvents = 'auto';

    // Scroll to top of grid
    grid.scrollIntoView({ behavior: 'smooth', block: 'start' });

    // Update URL
    history.pushState({}, '', `/products?page=${page}`);
}

function renderPagination(current, last) {
    const pag = document.getElementById('pagination');
    let html = '';
    for (let i = 1; i <= last; i++) {
        html += `<button data-page="${i}"
            class="page-btn ${i === current ? 'active' : ''}">
            ${i}
        </button>`;
    }
    pag.innerHTML = html;
}

Loading & Error States

Always show the user what's happening. Show a spinner while fetching, handle network errors gracefully, and show empty states when no results come back.

resources/js/ui-states.js — complete state handling 
const grid    = document.getElementById('productGrid');
const spinner = document.getElementById('spinner');

function showLoading() {
    spinner.style.display = 'flex';
    grid.style.opacity    = '0.3';
    grid.style.pointerEvents = 'none';
}

function hideLoading() {
    spinner.style.display = 'none';
    grid.style.opacity    = '1';
    grid.style.pointerEvents = 'auto';
}

function showEmpty(message = 'No products found.') {
    grid.innerHTML = `
        <div class="empty-state">
            <span>🔍</span>
            <p>${message}</p>
        </div>
    `;
}

function showError(err) {
    grid.innerHTML = `
        <div class="error-state">
            <span>⚠️</span>
            <p>Something went wrong: ${err.message}</p>
            <button onclick="location.reload()">Retry</button>
        </div>
    `;
}

async function fetchProducts(params = {}) {
    showLoading();
    try {
        const qs  = new URLSearchParams(params);
        const res = await fetch(`/ajax/products?${qs}`);

        if (!res.ok) throw new Error(`Server error: ${res.status}`);

        const data = await res.json();

        if (data.data.length === 0) {
            showEmpty('No products match your search.');
        } else {
            renderProducts(data.data, grid);
            renderPagination(data.current_page, data.last_page);
        }
    } catch (err) {
        showError(err);
    } finally {
        hideLoading();
    }
}

CSRF & POST Requests via AJAX

Laravel requires a CSRF token for all POST, PUT, PATCH, DELETE requests. For AJAX you send it in the header — never skip this or you'll get a 419 error.

🚨
419 Page Expired — this error means your AJAX POST is missing the CSRF token. Make sure you have <meta name="csrf-token" content="{{ csrf_token() }}"> in your layout's <head> and send it in every POST request header.
resources/views/layouts/app.blade.php — required meta tag 
<head>
    <meta charset="UTF-8">
    <!-- Required for ALL AJAX POST requests -->
    <meta name="csrf-token" content="{{ csrf_token() }}">
</head>
resources/js/http.js — reusable fetch helper with CSRF 
// Get the CSRF token from the meta tag once
const CSRF = document
    .querySelector('meta[name="csrf-token"]')
    ?.content || '';

// Reusable POST helper — use this everywhere instead of raw fetch()
async function post(url, body = {}) {
    const res = await fetch(url, {
        method:  'POST',
        headers: {
            'Content-Type':     'application/json',
            'Accept':           'application/json',
            'X-CSRF-TOKEN':     CSRF,
            'X-Requested-With': 'XMLHttpRequest',
        },
        body: JSON.stringify(body),
    });
    if (res.status === 401) { window.location.href = '/login'; return; }
    if (res.status === 403) { throw new Error('Forbidden'); }
    if (res.status === 419) { throw new Error('CSRF token expired — reload page'); }
    if (!res.ok)              { throw new Error(`Error ${res.status}`); }
    return res.json();
}

// Usage — add to cart:
const data = await post(`/cart/add/${productId}`, { quantity: 1 });
document.getElementById('cart-badge').textContent = data.cartCount;

// Usage — save wishlist item:
const data = await post('/wishlist/toggle', { product_id: 5 });
updateWishlistBtn(data.wishlisted);

Debounce & Performance Tips

Without debouncing, every keystroke fires a database query. Debouncing delays the request until the user pauses typing — dramatically reducing server load.

resources/js/utils.js — reusable debounce + abort controller 
// ── Debounce function ────────────────────────────────
function debounce(fn, delay = 350) {
    let timer;
    return (...args) => {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), delay);
    };
}

// ── AbortController — cancel in-flight requests ──────
// If user types fast, cancel the previous fetch before
// the new one fires so old results don't override new ones
let abortController;

async function searchProducts(query) {
    // Cancel any pending request
    if (abortController) abortController.abort();
    abortController = new AbortController();

    try {
        const res = await fetch(`/ajax/products?search=${query}`, {
            signal: abortController.signal  // tied to the controller
        });
        const data = await res.json();
        renderProducts(data.data);
    } catch (err) {
        if (err.name === 'AbortError') return; // expected — ignore
        showError(err);
    }
}

// Attach with 350ms debounce
const debouncedSearch = debounce(searchProducts, 350);
searchInput.addEventListener('input', e => debouncedSearch(e.target.value));
⚡
Performance checklist for AJAX routes:
✅ Use select('id','name','price','image') — only fetch columns you need
✅ Add database indexes on columns you filter/search (e.g. name, category_id)
✅ Use paginate(12) — never all() on large tables
✅ Cache category lists with Cache::remember() — they rarely change
✅ Use debounce (300–400ms) on all search inputs
Controller optimization — only fetch what you need 
public function ajaxIndex(Request $request)
{
    $products = Product::with(['category:id,name'])  // only id+name from category
        ->select('id', 'name', 'price', 'stock', 'image', 'category_id')
        ->where('stock', '>', 0)
        ->when($request->search, fn($q, $s) =>
            $q->where('name', 'like', "%{$s}%")
        )
        ->when($request->category_id, fn($q, $c) =>
            $q->where('category_id', $c)
        )
        ->paginate(12);

    return response()->json($products);
}
