Laravel Project Folders
Explained

Every file you write in Laravel belongs somewhere specific. This guide walks through the five most important folders — resources, public, database, config, and app — with real examples, file naming rules, and what goes where.

📁 resources/ 📁 public/ 📁 database/ 📁 config/ 📁 app/
📁 /resources

resources/

Everything the user sees lives here. Blade templates, CSS, JavaScript, and translation files. This is where you write your frontend code before it gets compiled or served.

📂 Sub-folders

🎨 resources/views/

All your Blade template files. This is where HTML lives in Laravel. Every page, component, and layout is a .blade.php file here.

  • layouts/app.blade.php
  • layouts/guest.blade.php
  • products/index.blade.php
  • products/show.blade.php
  • cart/index.blade.php
  • auth/login.blade.php
  • components/nav.blade.php
⚡ resources/js/

JavaScript source files. Write your JS here, Vite (Laravel 12) or Mix (Laravel 8) bundles it into public/build/.

  • app.js — main entry point
  • bootstrap.js — Axios, Echo setup
  • cart.js — AJAX cart logic
  • search.js — live search
🎨 resources/css/

CSS / SCSS source files. Vite compiles these into public/build/assets/. With Tailwind, this file is mostly just @tailwind directives.

  • app.css — main stylesheet
  • admin.css — admin overrides
🌍 resources/lang/

Translation files for multi-language support. Return arrays of strings keyed by identifier.

  • en/messages.php
  • en/validation.php
  • fil/messages.php

📄 Blade Template Rules

📐
Always use a layout file
Put repeated HTML (nav, footer, head tags) in a layout and extend it from every page. Never repeat the same HTML in two places.
resources/views/layouts/app.blade.php
🧩
Use components for reusable UI pieces
Product cards, alert banners, buttons — anything you use more than once should be a Blade component in resources/views/components/.
resources/views/components/product-card.blade.php → <x-product-card />
📂
Mirror your routes in your view folders
If a route is /products/show, its view should be at resources/views/products/show.blade.php. Keeps things predictable.
Route /admin/orders → resources/views/admin/orders/index.blade.php

💡
Laravel 8 uses Mix, Laravel 12 uses Vite. In Laravel 8, call assets with mix('css/app.css'). In Laravel 12 use @vite(['resources/css/app.css']). The resources/ folder structure is the same for both.
📁 /public

public/

The only folder the web server can see. Your domain points here. index.php is the entry point for every request. Never put sensitive files here — keep business logic in app/.

📂 What's Inside

🚪 public/index.php

The front controller. Every single HTTP request enters Laravel through this file. Don't edit it — Laravel manages it.

  • Loads vendor/autoload.php
  • Boots bootstrap/app.php
  • Handles the request → returns response
🖼️ public/images/

Static images that don't change — logos, icons, placeholder images. Reference with asset('images/logo.png').

  • logo.png
  • placeholder.jpg
  • favicon.ico
🔗 public/storage/

A symlink pointing to storage/app/public/. User-uploaded files (product images, avatars) live here. Created by php artisan storage:link.

  • products/laptop.jpg
  • avatars/user-1.jpg
📦 public/build/ (Laravel 12)

Vite outputs compiled CSS and JS here. Auto-generated — never edit these files manually. Add public/build to .gitignore.

  • assets/app-[hash].css
  • assets/app-[hash].js
  • manifest.json
📦 public/css/ & public/js/ (Laravel 8)

Laravel Mix compiled output in Laravel 8. Mix writes here from resources/ source files via npm run dev.

  • css/app.css
  • js/app.js
  • mix-manifest.json
📄 public/.htaccess

Apache rewrite rules. Routes all requests to index.php so Laravel's router handles them. Required for pretty URLs without /index.php/ in the path.

⚠️ Golden Rules for public/

🚫
Never put PHP business logic in public/
The web server can serve anything in public/ directly. If you put a PHP file with database credentials here, it could be read by anyone. Business logic belongs in app/.
🔗
User uploads go to storage/, accessed via public/storage/
Store files with Storage::disk('public')->put(). Run php artisan storage:link once to create the symlink. Reference in Blade with asset('storage/products/image.jpg').
php artisan storage:link → creates public/storage → symlink to storage/app/public
🌐
On shared hosting, point your domain to public/
Your domain's document root must be /path/to/project/public, not the project root. This is the #1 deployment mistake beginners make.
cPanel: Document Root → /home/username/laravel-shop/public

Uploading a file and storing it in public/storage 
// In your controller (e.g. ProductController@store)
public function store(Request $request)
{
    $request->validate([
        'image' => 'required|image|mimes:jpg,jpeg,png,webp|max:2048',
    ]);

    // Store to storage/app/public/products/
    // Accessible via public/storage/products/filename.jpg
    $path = $request->file('image')->store('products', 'public');

    Product::create([
        'name'  => $request->name,
        'image' => $path,  // stored as "products/xxx.jpg"
    ]);
}
📁 /database

database/

Every database-related file lives here: table schemas (migrations), fake data generators (factories), and database population scripts (seeders). This folder is version-controlled so your whole team shares the same DB structure.

📂 Sub-folders

🏗️ database/migrations/

PHP files that define your database tables. Each migration has an up() to create/alter and a down() to reverse it. Filename includes a timestamp for ordering.

  • 2024_01_01_000000_create_users_table.php
  • 2024_01_01_000001_create_categories_table.php
  • 2024_01_01_000002_create_products_table.php
  • 2024_01_01_000003_create_orders_table.php
🏭 database/factories/

Factory classes that define how to generate fake model data using Faker. Used by seeders and tests to quickly fill the DB with realistic records.

  • UserFactory.php
  • ProductFactory.php
  • OrderFactory.php
🌱 database/seeders/

Scripts that populate the database. DatabaseSeeder.php is the main one — it calls other seeders. Run with php artisan db:seed.

  • DatabaseSeeder.php — main entry
  • CategorySeeder.php
  • ProductSeeder.php
  • UserSeeder.php

💻 Code Examples

database/migrations/2024_01_01_create_products_table.php 
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('products', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->text('description')->nullable();
            $table->decimal('price', 10, 2);
            $table->unsignedInteger('stock')->default(0);
            $table->string('image')->nullable();
            $table->boolean('is_featured')->default(false);
            $table->foreignId('category_id')
                   ->constrained()
                   ->cascadeOnDelete();
            $table->timestamps();  // created_at, updated_at
            $table->softDeletes(); // deleted_at (optional)
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('products');
    }
};
database/factories/ProductFactory.php 
class ProductFactory extends Factory
{
    public function definition(): array
    {
        return [
            'name'        => $this->faker->words(3, true),
            'description' => $this->faker->paragraph(),
            'price'       => $this->faker->randomFloat(2, 50, 5000),
            'stock'       => $this->faker->numberBetween(0, 100),
            'is_featured' => $this->faker->boolean(20), // 20% chance
            'category_id' => Category::inRandomOrder()->value('id'),
        ];
    }
}
database/seeders/DatabaseSeeder.php 
public function run(): void
{
    // 1. Create categories first (products depend on them)
    Category::factory()->createMany([
        ['name' => 'Electronics'],
        ['name' => 'Clothing'],
        ['name' => 'Books'],
        ['name' => 'Footwear'],
    ]);

    // 2. Create products using the factory
    Product::factory(50)->create();

    // 3. Create admin user
    User::factory()->create([
        'name'     => 'Admin',
        'email'    => '[email protected]',
        'password' => bcrypt('password'),
        'role'     => 'admin',
    ]);

    // 4. Create test customers
    User::factory(20)->create();
}

// Commands:
// $ php artisan db:seed               — run seeders only
// $ php artisan migrate:fresh --seed  — reset DB + seed
Common migration commands 
# Generate files
$ php artisan make:migration create_products_table
$ php artisan make:migration add_stock_to_products_table --table=products
$ php artisan make:factory ProductFactory --model=Product
$ php artisan make:seeder ProductSeeder

# Run migrations
$ php artisan migrate              # run pending migrations
$ php artisan migrate:rollback      # undo last batch
$ php artisan migrate:fresh         # drop all + re-run
$ php artisan migrate:fresh --seed  # drop all + re-run + seed
$ php artisan migrate:status        # see which ran
📁 /config

config/

All configuration files for your Laravel app. Each file returns an array. Values come from .env via the env() helper. Never hardcode secrets here — put them in .env and reference with env().

📄 Key Config Files

⚙️ config/app.php

App name, environment, debug mode, URL, timezone, locale, encryption key, and registered service providers.

  • 'name' — APP_NAME from .env
  • 'debug' — APP_DEBUG from .env
  • 'timezone' — e.g. 'Asia/Manila'
  • 'providers' — registered services
🗄️ config/database.php

All database connection configs. Default is mysql. Reads host, port, DB name, username, password from .env.

  • 'default' — DB_CONNECTION
  • 'connections' — mysql, pgsql, sqlite
  • 'redis' — Redis config
📧 config/mail.php

Email sending config. Supports SMTP, Mailgun, SES, Postmark, sendmail. Set MAIL_MAILER in .env.

  • MAIL_MAILER — smtp / mailgun
  • MAIL_HOST — smtp server
  • MAIL_FROM_ADDRESS
🗃️ config/cache.php

Cache driver config. Options: file (default), redis, database, array, memcached. Set CACHE_DRIVER in .env.

🔐 config/auth.php

Authentication guards and user providers. Defines which model is used for auth (User::class by default), and which table for passwords.

💾 config/session.php

Session driver, lifetime, cookie name, secure flag. The cart session uses this. SESSION_DRIVER in .env: file, cookie, database, redis.

⚠️
After editing .env, run php artisan config:clear — Laravel caches config values for performance. If you change .env without clearing, your app may still use old values.
📁 /app

app/

The heart of your Laravel application. All your PHP business logic lives here — controllers that handle requests, models that talk to the database, middleware that filters requests, and service providers that boot everything up.

📂 Sub-folders

🎮 app/Http/Controllers/

Controller classes that receive HTTP requests and return responses. One controller per resource (Product, Order, Cart, etc.).

  • Auth/LoginController.php
  • Admin/ProductController.php
  • CartController.php
  • ProductController.php
  • OrderController.php
🛡️ app/Http/Middleware/

Filter classes that run before or after controllers. Check auth state, roles, rate limiting, logging, etc.

  • Authenticate.php — auth check
  • AdminMiddleware.php — role check
  • RedirectIfAuthenticated.php
📋 app/Http/Requests/

Form Request classes for validation. Move validation logic out of controllers into dedicated classes. Auto-validated before the controller method runs.

  • StoreProductRequest.php
  • UpdateProductRequest.php
  • PlaceOrderRequest.php
🗃️ app/Models/

Eloquent model classes — one per database table. Define $fillable, relationships, casts, scopes, and accessors here.

  • User.php
  • Product.php
  • Category.php
  • Order.php
  • OrderItem.php
📡 app/Providers/

Service provider classes that boot your app. Register event listeners, bind interfaces to implementations, share view data globally.

  • AppServiceProvider.php
  • AuthServiceProvider.php
  • RouteServiceProvider.php
  • EventServiceProvider.php
👂 app/Listeners/

Event listener classes that react to events (login, order placed, etc.). Wired to events in EventServiceProvider.

  • MergeCartOnLogin.php
  • SendOrderConfirmation.php

💻 Code Examples

app/Models/Product.php — full model 
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\SoftDeletes;

class Product extends Model
{
    use HasFactory, SoftDeletes;

    // Columns allowed for mass assignment
    protected $fillable = [
        'name', 'description', 'price',
        'stock', 'image', 'is_featured', 'category_id',
    ];

    // Auto type casting
    protected $casts = [
        'price'       => 'float',
        'is_featured' => 'boolean',
    ];

    // Relationships
    public function category()
    {
        return $this->belongsTo(Category::class);
    }

    public function orderItems()
    {
        return $this->hasMany(OrderItem::class);
    }

    // Local scope — reusable query filter
    public function scopeInStock($query)
    {
        return $query->where('stock', '>', 0);
    }

    // Accessor — formatted price
    public function getFormattedPriceAttribute()
    {
        return '₱ ' . number_format($this->price, 2);
    }
}

// Usage:
// Product::inStock()->get()      ← uses the scope
// $product->formatted_price      ← uses the accessor
app/Http/Controllers/ProductController.php 
namespace App\Http\Controllers;

use App\Models\Product;
use App\Models\Category;
use App\Http\Requests\StoreProductRequest;
use Illuminate\Http\Request;

class ProductController extends Controller
{
    // GET /products
    public function index(Request $request)
    {
        $products = Product::with('category')
            ->inStock()
            ->when($request->search, fn($q, $s) =>
                $q->where('name', 'like', "%{$s}%")
            )
            ->latest()->paginate(config('shop.per_page', 12));

        $categories = Category::all();

        return view('products.index', compact('products', 'categories'));
    }

    // GET /products/{product}
    public function show(Product $product)
    {
        $related = Product::where('category_id', $product->category_id)
            ->where('id', '!=', $product->id)
            ->inStock()->limit(4)->get();

        return view('products.show', compact('product', 'related'));
    }
}
app/Http/Requests/StoreProductRequest.php — Form Request 
class StoreProductRequest extends FormRequest
{
    // Who is allowed to make this request?
    public function authorize(): bool
    {
        return auth()->user()->role === 'admin';
    }

    // Validation rules
    public function rules(): array
    {
        return [
            'name'        => 'required|string|max:255',
            'price'       => 'required|numeric|min:0',
            'stock'       => 'required|integer|min:0',
            'category_id' => 'required|exists:categories,id',
            'image'       => 'nullable|image|max:2048',
        ];
    }

    // Custom error messages
    public function messages(): array
    {
        return [
            'category_id.exists' => 'Please select a valid category.',
        ];
    }
}

app/Providers/AppServiceProvider.php — share data to all views 
use App\Models\Category;
use Illuminate\Support\Facades\View;

public function boot(): void
{
    // Share categories to ALL Blade views automatically
    // Now every view can use $categories without controller code
    View::share('categories', Category::all());

    // Share cart count to all views
    View::composer('*', function ($view) {
        $view->with('cartCount', count(session('cart', [])));
    });
}
