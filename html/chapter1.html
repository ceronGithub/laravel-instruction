Install Laragon

Laragon is a fast, lightweight local development environment for Windows. It bundles Apache/Nginx, PHP, MySQL/MariaDB, and more — all in one click.

✅ No PATH or system config needed — just install and run.

2

Verify Composer & PHP

Laragon adds PHP and Composer to your PATH automatically. Open Laragon's Terminal (or Windows Terminal) and verify:

bash 
$ php --version
PHP 8.2.10 (cli)

$ composer --version
Composer version 2.6.5
⚠️
'php' is not recognized? In Laragon, go to Menu → PHP → Add PHP to PATH, then restart your terminal. Alternatively add C:\laragon\bin\php\php8.x manually to System PATH.
3

Create a Laravel 8 Project

Navigate to C:\laragon\www and run:

bash 
# Navigate to Laragon's www folder
$ cd C:\laragon\www

# Create a Laravel 8 project
$ composer create-project laravel/laravel:^8.0 shop-laravel8

# OR using the Laravel installer:
$ laravel new shop-laravel8 --version=8

Once done, you can access it at http://shop-laravel8.test (Laragon auto-creates virtual hosts!).

🌐
Auto Virtual Hosts: Laragon creates a .test domain for every folder inside C:\laragon\www. No manual Apache config needed!
4

Create a Laravel 12 Project

Laravel 12 requires PHP 8.2+. Laragon Full ships with it. Create the project:

bash 
$ cd C:\laragon\www

# Latest Laravel (12 as of 2025)
$ composer create-project laravel/laravel shop-laravel12

# Check Laravel version inside the project:
$ cd shop-laravel12
$ php artisan --version
Laravel Framework 12.x.x
📌
Laravel 8 vs 12 differences: Laravel 12 has a cleaner directory structure, improved Vite integration (replacing Mix), and the php artisan install:api command for API scaffolding. The core concepts — routes, models, controllers, Blade — remain the same.
5

Project Structure Explained

Here's what each folder does in a fresh Laravel project:

shop/ ├── app/ │ ├── Http/ │ │ ├── Controllers/ ← Your controller classes live here │ │ └── Middleware/ ← Auth, CORS, etc. │ └── Models/ ← Eloquent model classes ├── config/ ← App settings (database, mail, etc.) ├── database/ │ ├── migrations/ ← ✨ Schema files — create tables here │ └── seeders/ ← Fake data generators ├── public/ ← Web root — index.php, images, css ├── resources/ │ └── views/ ← ✨ Blade templates (.blade.php) ├── routes/ │ └── web.php ← ✨ Define your URL routes here ├── storage/ ← Logs, uploaded files, cache ├── .env ← ✨ Environment config (DB, APP_KEY, etc.) └── artisan ← Laravel CLI tool

Common Setup Errors & Fixes

🚨
No application encryption key has been specified.
Run: php artisan key:generate — this sets APP_KEY in your .env file.
🚨
PHP version not compatible.
Laravel 12 needs PHP 8.2+. In Laragon, go to Menu → PHP → switch PHP version.
🚨
storage/ or bootstrap/cache/ permission denied.
Run: php artisan storage:link and ensure those folders are writable.
🚨
OpenSSL extension not found.
In Laragon, edit php.ini (Menu → PHP → php.ini) and ensure extension=openssl is uncommented.
Essential first-run commands 
$ php artisan key:generate        # Generate APP_KEY
$ php artisan storage:link         # Create public/storage symlink
$ php artisan config:clear         # Clear config cache
$ php artisan cache:clear          # Clear application cache
$ composer install                 # Install dependencies
