Configure .env for Database

Every Laravel project has a .env file at the root. This is where you put your database credentials. Open it and update the DB_* variables:

.env 
# Application settings
APP_NAME=LaravelShop
APP_ENV=local
APP_KEY=base64:xxxx...  # auto-set by key:generate
APP_DEBUG=true
APP_URL=http://localhost

# Database — Laragon defaults:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_shop
DB_USERNAME=root
DB_PASSWORD=          # Laragon default is empty
💡
Create the database first! Open phpMyAdmin at http://localhost/phpmyadmin (Laragon provides this), create a new database called laravel_shop, then run migrations.
2

MySQL vs MariaDB in Laragon

Laragon ships with both MySQL and MariaDB. You can switch between them. For Laravel development they're interchangeable — same SQL syntax, same Eloquent code.

Feature MySQL 8.x MariaDB 10.x
Default Port 3306 3306
Laravel .env DB_CONNECTION=mysql DB_CONNECTION=mysql
Performance Great for large datasets Slightly faster for reads
JSON support Full JSON columns Full JSON columns
Open source Oracle-owned Community fork (100% free)
Laragon switch Menu → MySQL → Switch to MariaDB

Migrations — Create Database Tables

Migrations are version-controlled schema files. You define your table structure in PHP, and Laravel creates the SQL for you.

bash — generate migrations 
# Create model + migration + controller all at once:
$ php artisan make:model Product -mcr
$ php artisan make:model Category -mcr
$ php artisan make:model Order -mcr
$ php artisan make:model OrderItem -mcr
database/migrations/create_products_table.php 
public function up(): void
{
    Schema::create('products', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->text('description')->nullable();
        $table->decimal('price', 10, 2);
        $table->unsignedInteger('stock')->default(0);
        $table->string('image')->nullable();
        $table->boolean('is_featured')->default(false);
        $table->foreignId('category_id')->constrained()->cascadeOnDelete();
        $table->timestamps();
    });
}
bash — run migrations 
$ php artisan migrate

INFO  Running migrations.
✓  2024_01_01_000000_create_users_table ............... 42ms DONE
✓  2024_01_01_000001_create_categories_table ......... 38ms DONE
✓  2024_01_01_000002_create_products_table ........... 41ms DONE

# Reset and re-run all migrations:
$ php artisan migrate:fresh

# Reset + seed:
$ php artisan migrate:fresh --seed

Models & $fillable

Eloquent models represent database tables. The $fillable array defines which columns can be mass-assigned (i.e., via Product::create([...])).

app/Models/Product.php 
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class Product extends Model
{
    use HasFactory;

    // Columns that can be mass-assigned
    protected $fillable = [
        'name', 'description', 'price',
        'stock', 'image', 'is_featured',
        'category_id',
    ];

    // Cast price to float automatically
    protected $casts = [
        'price'       => 'float',
        'is_featured' => 'boolean',
    ];
}

Eloquent Relationships

Eloquent makes table relationships simple. Here's how our e-commerce models relate:

User
hasMany Orders
Order
hasMany OrderItems
Product
app/Models/Product.php — with relationships 
// Product belongs to a Category
public function category()
{
    return $this->belongsTo(Category::class);
}

// Product can be in many OrderItems
public function orderItems()
{
    return $this->hasMany(OrderItem::class);
}

// ────────────────────────────────────────────
// app/Models/Order.php
public function user()
{
    return $this->belongsTo(User::class);
}

public function items()
{
    return $this->hasMany(OrderItem::class);
}

// ────────────────────────────────────────────
// app/Models/User.php
public function orders()
{
    return $this->hasMany(Order::class);
}

Seed the Database

Use Factories and Seeders to fill your database with realistic fake data for development.

database/seeders/DatabaseSeeder.php 
public function run(): void
{
    // Create admin user
    User::factory()->create([
        'name'     => 'Admin',
        'email'    => '[email protected]',
        'password' => bcrypt('password'),
    ]);

    // Create 5 categories
    Category::factory(5)->create();

    // Create 50 products tied to categories
    Product::factory(50)->create();

    // Create 20 test customers
    User::factory(20)->create();
}

// Run it:
// $ php artisan db:seed
// $ php artisan migrate:fresh --seed

Eloquent Queries Cheat Sheet

Eloquent ORM — common queries 
// Get all products
$products = Product::all();

// Find by ID
$product = Product::find(1);
$product = Product::findOrFail(1); // throws 404 if not found

// Filter & sort
$featured = Product::where('is_featured', true)
    ->where('stock', '>', 0)
    ->orderBy('price')
    ->get();

// Eager load relationships (avoids N+1 query problem)
$products = Product::with(['category'])->paginate(12);

// Create
$product = Product::create(['name' => 'Laptop', 'price' => 999.99]);

// Update
$product->update(['stock' => 50]);

// Delete
$product->delete();

// Aggregates
$total = Product::sum('price');
$count = Product::where('stock', '>', 0)->count();
