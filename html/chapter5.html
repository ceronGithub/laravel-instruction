ngrok — Instant Public URL

ngrok creates a secure tunnel from a public URL to your local Laragon server. Perfect for demos, client previews, or testing webhooks.

bash — setup ngrok 
# 1. Download ngrok from ngrok.com/download
# 2. Create free account and get your authtoken
# 3. Configure ngrok
$ ngrok config add-authtoken YOUR_TOKEN_HERE

# 4. Make sure your Laravel is running:
$ php artisan serve
#    Running on http://127.0.0.1:8000

# 5. In a NEW terminal, start ngrok tunnel:
$ ngrok http 8000
ngrok tunnel output
Session Status online
Account [email protected]
Version 3.x.x
Forwarding https://abc1234.ngrok-free.app → http://localhost:8000
Connections ttl=0 opn=0 rt1=0.00 rt5=0.00 p50=0

Now share https://abc1234.ngrok-free.app with anyone! Your local Laravel app is instantly public. No hosting needed.

⚠️
Trusted hosts: Add the ngrok URL to your .env and config/app.php trusted hosts, or Laravel may reject requests. Set APP_URL=https://abc1234.ngrok-free.app in your .env.
2

Production .env Settings

Before going live, update your .env to turn off debug mode and set the production URL:

.env — production settings 
# CRITICAL: Turn off debug in production!
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourapp.com

# Database on your server
DB_HOST=127.0.0.1
DB_DATABASE=yourdb_name
DB_USERNAME=yourdb_user
DB_PASSWORD=your_strong_password

# Use file cache in production (faster)
CACHE_DRIVER=file
SESSION_DRIVER=database
QUEUE_CONNECTION=database
🚨
NEVER commit .env to Git! The .env file is already in .gitignore by default. Always copy it manually to your server or use environment variables through your hosting panel.

Deploy to Shared Hosting (cPanel)

Budget-friendly option. Works on Hostinger, Namecheap, etc. The trick is pointing the domain to Laravel's public/ folder.

Step-by-step shared hosting deploy 
# 1. On your local machine — ZIP the project (exclude vendor/ and node_modules/)
# 2. Upload via cPanel File Manager to /home/username/laravel-shop
# 3. Upload /public to /home/username/public_html

# 4. Edit public_html/index.php — fix paths:
require __DIR__.'/../laravel-shop/vendor/autoload.php';
$app = require_once __DIR__.'/../laravel-shop/bootstrap/app.php';

# 5. In cPanel Terminal (or SSH):
$ cd /home/username/laravel-shop
$ composer install --no-dev --optimize-autoloader
$ php artisan key:generate
$ php artisan migrate --force
$ php artisan storage:link
💡
Hostinger tip: They now offer a one-click Laravel installer in hPanel. Just click "Auto Install" and it handles the folder structure for you.

VPS Deployment with Nginx

Full control. Use DigitalOcean, Vultr, or any Ubuntu VPS. We'll use Nginx + PHP-FPM.

bash — server setup (Ubuntu 22.04) 
# Install dependencies
$ sudo apt update
$ sudo apt install nginx php8.2-fpm php8.2-mysql php8.2-mbstring \
    php8.2-xml php8.2-curl php8.2-zip composer mysql-server -y

# Clone your project
$ cd /var/www
$ git clone https://github.com/you/laravel-shop.git
$ cd laravel-shop
$ composer install --no-dev --optimize-autoloader
$ cp .env.example .env
$ php artisan key:generate
$ php artisan migrate --force
$ php artisan storage:link
$ sudo chown -R www-data:www-data /var/www/laravel-shop/storage
$ sudo chown -R www-data:www-data /var/www/laravel-shop/bootstrap/cache
/etc/nginx/sites-available/laravel-shop 
server {
    listen 80;
    server_name yourapp.com www.yourapp.com;
    root /var/www/laravel-shop/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
bash — enable the site 
$ sudo ln -s /etc/nginx/sites-available/laravel-shop \
    /etc/nginx/sites-enabled/
$ sudo nginx -t   # test config
$ sudo systemctl reload nginx
✓  Your app is now live at http://yourapp.com
5

Free SSL with Let's Encrypt

Add HTTPS to your domain using Certbot — it's free and auto-renews.

bash
$ sudo apt install certbot python3-certbot-nginx -y $ sudo certbot --nginx -d yourapp.com -d www.yourapp.com # Follow prompts — certbot configures Nginx automatically! ✓ Certificate issued: /etc/letsencrypt/live/yourapp.com/ ✓ Nginx configured for HTTPS auto-redirect ✓ Auto-renewal set via systemd timer
🔒
Update your .env after SSL: Change APP_URL=https://yourapp.com (https, not http), then run php artisan config:cache to apply it.
6

Production Optimize Commands

Run these commands after every deployment to cache config, routes, and views for maximum performance:

bash — deploy script 
#!/bin/bash — deploy.sh
$ git pull origin main

$ composer install --no-dev --optimize-autoloader

$ php artisan config:cache    # Cache .env & config files
$ php artisan route:cache     # Cache all routes
$ php artisan view:cache      # Precompile Blade templates
$ php artisan event:cache     # Cache event listeners

$ php artisan migrate --force # Apply any new migrations

✓  Deployment complete!

# If something breaks, clear all caches:
$ php artisan optimize:clear
